## ✨ Key Features

🛍️ **Full E-Commerce** - Cart, checkout, order tracking, payment integration  
🏪 **Nursery Network** - Partner directory with location search  
📚 **Educational Blog** - Plant knowledge & Ayurvedic insights  
👤 **User Profiles** - Order history, addresses, preferences  
🔧 **Admin Dashboard** - Complete inventory & order management  
🎨 **Modern UI/UX** - Responsive design with smooth animations  
🌙 **Dark/Light Mode** - Theme customization  
📱 **Mobile Optimized** - Perfect on all devices

## 🛠️ Tech Stack

**Frontend:** React 18 • Vite • TailwindCSS • Framer Motion • React Router  
**Backend:** Node.js • Express • Firebase • Firestore  
**UI Components:** Shadcn/ui • Lucide Icons  
**Tools:** TypeScript • ESLint • Appwrite

## ⚡ Quick Start

### Prerequisites
Node.js (v16+) • Firebase Project • Git

### Installation
```bash
# Clone repository
git clone https://github.com/Aryan02004/VedicFlora.git
cd VedicFlora

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local
# Add your Firebase credentials

# Start development
npm run dev
```

### Backend Setup
```bash
cd Backend-vedicflora
npm install
# Configure environment variables in .env
npm run dev
```

🌐 **Frontend:** http://localhost:3000  
🔧 **Backend:** http://localhost:5000
